## 平台专用能力如何处理

| 原平台能力 | 当前路线 |
|---|---|
| Lenmu list_models/付费工具 | LibTV model search/schema + 节点；实际报价与确认后run |
| set_budget/自动新画布 | 明确LibTV画布UUID；本地预算/任务账本，无服务器硬上限保证 |
| save_character/Avatar/剧本卡自动引用 | 本地设定卡 + 实际参考节点/顺序；原生角色库/注册入口需验证 |
| edit_region/局部改图 | 查LibTV可用图片编辑模式；无法验证区域锁定时不给保证 |
| reshoot/continue视频 | 按LibTV实时schema判断编辑/延长输入；未验证则本地修复或提单镜重拍方案 |
| generate_audio/OmniHuman | 查LibTV audio与音频驱动视频模型，先音频试听再动画，能力未实测 |
| assemble_film/export_premiere | 本地剪辑清单、ffmpeg和用户指定编辑工具；LibTV同类功能待验证，不宣称免费或限制相同 |
| publish_play/create_series/play_status | 先交故事图/各集成片/状态表；发布托管与统计无已验证映射 |

## 与原版有意不同的部分

- 用户默认Seedance2.5/1080P/9:16/开启声音，不能被旧版模型推荐或低成本试拍覆盖。
- 每次生成先报实际积分并确认，包括图、音频、重拍和付费重试；不沿用旧美元价格或以总预算代授权。
- 构图38%/62%、正面镜头次数、胶片风格等保留为创作工具，不变成阻碍用户已明确产品镜头的机械限制。
- 不强制将未知色彩视频按BT.601解释，不以微小静态像素误差作为色彩矩阵可靠证据。
- 原版用于绕过人脸识别的微马赛克步骤/脚本不迁移；合规与授权按当前平台要求执行。
- 测试案例的5秒/1条、既有任务ID、画布UUID和报价不是通用默认，不写进可复用执行目标。
